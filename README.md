# Data Science Salary Dashboard — Excel

## Project Overview
This project explores salary trends in data science roles using Microsoft Excel. The dashboard summarizes salary-related information through charts and key metrics.

## Objectives
- Explore salary patterns across job titles and countries.
- Compare salary information across employment types.
- Present key metrics in a clear, visual format.

## Tools Used
- Microsoft Excel
- Excel charts and dashboard formatting

## Dashboard Highlights
- Median salary
- Job platform with the highest representation in the dataset
- Job count
- Salary comparisons by job title, country, and employment type
